What does this page tell me?

It reads computer resources and, when configured, the room ROS service list. It does not call device services, operate lights or blinds, inspect recordings, or restart anything. “Service listed” means the expected interface names are registered, not that a physical device is healthy.

For room controls, use the cabinet panel with the room host. If information is stale or unavailable, coordinate with staff; this page provides no recovery actions.
